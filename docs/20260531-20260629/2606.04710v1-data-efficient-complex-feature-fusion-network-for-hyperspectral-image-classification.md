## 摘要
本文提出了一种基于注意力的双分支复杂特征融合网络（CFFN）的数据高效变体，用于高光谱图像分类。所提出的模型称为DE-CFFN，保留了原始的双流结构：实值神经网络（RVNN）处理标准高光谱图像块，而复值神经网络（CVNN）处理其傅里叶变换后的对应部分。本文的主要贡献在于特征提取过程和架构增强。使用因子分析进行降维，相比主成分分析提供了更好的潜在特征表示。此外，RVNN和CVNN分支在结构上进行了修改，通过连续将3D卷积层中的滤波器数量减半来降低复杂度。两个分支的输出被拼接起来，并通过一个挤压激励（SE）模块以增强联合特征表示。在帕维亚大学和萨利纳斯数据集上评估，DE-CFFN实现了与CFFN相当的分类性能，同时显著减少了模型大小、内存消耗和推理延迟，使其适用于实时高光谱成像应用。

## Abstract
This work presents a data-efficient variant of the Attention-Based Dual-Branch Complex Feature Fusion Network (CFFN) for hyperspectral image classification. The proposed model, termed DE-CFFN, retains the original two-stream structure: the Real-Valued Neural Network (RVNN) processes standard hyperspectral patches, while the Complex-Valued Neural Network (CVNN) handles their Fourier-transformed counterparts. The main contribution of this work lies in the feature extraction process and architectural enhancement. Factor Analysis is used for dimensionality reduction, offering improved latent feature representation over Principal Component Analysis. Additionally, both the RVNN and CVNN streams are structurally modified by successively halving the number of filters in the 3D convolutional layers to reduce complexity. The outputs of both branches are concatenated and passed through a Squeeze and Excitation (SE) block to enhance joint feature representation. Evaluated on the Pavia University and Salinas datasets, DE-CFFN achieves classification performance comparable to CFFN, while significantly reducing model size, memory consumption, and inference latency, making it suitable for real-time hyperspectral imaging applications.

## 1. 核心问题与整体含义（研究动机和背景）

高光谱图像（HSI）分类是遥感领域的重要任务，能够通过丰富的空间和光谱信息实现精细地物识别。然而，高光谱数据的高维度特性带来了“休斯现象”，导致传统机器学习方法性能下降，且深度学习模型（如3D CNN）虽然效果好，但计算复杂度高、参数多，不利于实时应用（如无人机或卫星板载处理）。本文旨在解决现有高光谱分类模型（如Attention-Based Dual-Branch Complex Feature Fusion Network, CFFN）在资源受限场景下的效率和实时性问题，提出一种数据高效变体DE-CFFN，在保持分类精度的同时大幅降低计算开销。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
DE-CFFN保留CFFN的双流结构（实值神经网络RVNN和复值神经网络CVNN），但通过以下三点改进实现数据高效：
- **用因子分析（FA）替代主成分分析（PCA）** 进行降维，以提取更具判别性的潜在特征。
- **逐层减半3D卷积滤波器数**：RVNN和CVNN分支的3D卷积层滤波器数量从32→16→8，大幅减少参数。
- **双分支输出拼接后通过复数域Squeeze-and-Excitation（SE）模块**，增强联合特征表示。

### 关键技术细节
1. **输入预处理**：对高光谱数据立方体使用FA降维至11个谱带，然后提取15×15×11（Salinas）或9×9×11（PaviaU）的块。
2. **RVNN分支**：处理实数值块，包含3个3D卷积层（滤波器32→16→8，核3×3×3，步长1，ReLU激活）。
3. **CVNN分支**：处理经沿谱轴FFT得到的复数域块，采用相同结构的复数卷积和复数激活（Cartesian ReLU），提取幅值和相位信息。
4. **融合与注意力**：RVNN输出转换为复数域后与CVNN输出拼接，然后通过7个堆叠的复数SE块（通道缩减比r=8），自适应重新校准通道权重。
5. **分类**：融合特征展平后经过两个复数全连接层（128和64单元，dropout比率0.3和0.1），最后通过复数密集层+实数softmax输出分类结果。
6. **公式**：SE机制包括squeeze步骤（全局平均池化获得通道描述子z）和excitation步骤（两个全连接层+ReLU+Sigmoid生成权重s，再对输入通道加权）。

## 6. 主要结论与发现

1. **DE-CFFN在PU数据集上OA达到95.17%，Kappa 93.54，优于CFFN（94.35%, 92.7%）**，同时参数减少72.2%，内存减少72.2%，推理时间几乎不变。

3. **FA相较于PCA显著提升性能**：在PU上OA提升1.34%，SA上OA提升2.11%，AA提升6.30%，证明FA能更好地捕获潜在谱间依赖。
4. SE模块通常提升分类精度，尤其对光谱相似或少数类别。
5. DE-CFFN在保持高精度前提下，实现了模型轻量化，适合实时遥感应用。

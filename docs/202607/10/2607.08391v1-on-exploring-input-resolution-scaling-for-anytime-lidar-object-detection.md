## 摘要
在执行延迟与结果效用之间进行权衡（即任意时刻计算）以适应动态运行需求已被证明能够提升信息物理系统的性能。本文着重为处理激光雷达点云以实现三维目标检测的深度神经网络（DNN）启用任意时刻计算。我们提出了一种新颖方法，使得以支柱体或体素处理点云的模型能够进行多分辨率推理，从而允许输入根据时序需求动态缩放并以所需分辨率进行处理。重要的是，我们的内存高效方法只需部署单个DNN模型，无需部署多个针对不同输入分辨率分别训练的模型。我们还引入了一种感知截止时间的调度器，它通过运行时准确预测所有可能分辨率的执行时间（由于激光雷达点云的不规则性，这具有挑战性），为任何给定输入选择最高可能分辨率。在nuScenes自动驾驶数据集上的实验结果表明，我们的方法显著优于现有的激光雷达目标检测任意时刻计算方法。最后，我们将该方法部署在模拟自动驾驶系统中，在该系统中，它始终能够实现无碰撞导航，同时避免由环境复杂性引起的不必要停滞。

## Abstract
Making tradeoffs between execution latency and result utility (i.e., anytime computing) for adapting to dynamic operational requirements has been shown to enhance the performance of cyber-physical systems. In this work, we focus on enabling anytime computing for deep neural networks (DNNs) that process LiDAR point clouds for 3D object detection. We propose a novel method that enables multi-resolution inference for models that process point clouds as pillars or voxels, allowing the input to be dynamically scaled and processed at the resolution needed to meet timing requirements. Importantly, our memory-efficient approach requires the deployment of only a single DNN model, avoiding the need to deploy multiple models, each trained for a different input resolution. We also introduce a deadline-aware scheduler that selects the highest possible resolution for any given input by accurately predicting the execution time for all possible resolutions at runtime, which is challenging due to the irregularity of LiDAR point clouds. Experimental results on the nuScenes autonomous driving dataset demonstrate that our method significantly outperforms existing anytime computing approaches for LiDAR object detection. Finally, we deploy our approach in a simulated autonomous driving system, where it consistently enables collision-free navigation while avoiding unnecessary stalls caused by environmental complexity.

- **研究动机**：虽然调整输入分辨率（如将pillar从0.1m²放大到0.2m²）能直观地带来执行时间的减少，但传统方法需要为每种分辨率训练并部署一个独立的模型，这会产生巨大的内存开销，在嵌入式平台上不可行。此外，直接使用一个训练好的模型去推断其他未训练过的分辨率，会导致严重的精度下降。因此，本文旨在设计一种内存高效、能够动态调整输入分辨率的单模型框架，使其在运行时能够根据截止时间(deadline)自适应地选择最佳分辨率，以最大化检测精度。

### 论文提出的方法论

#### 核心思想
提出**MURAL**（MU lti-Resolution Anytime LiDAR）框架，一种用于LiDAR目标检测DNN的多分辨率任意时刻计算框架。其核心思想是，训练单个模型以支持**多个输入分辨率**（pillar/voxel尺寸），并在运行时由一个**截止时间感知的调度器**根据预测的执行时间，动态选择能够满足当前截止时间要求的**最高分辨率**（即最小的pillar/voxel尺寸），从而在延迟与精度之间实现高效权衡。

#### 关键技术细节
1.  **多分辨率训练与推理**：
    - **共享权重，专用BN**：训练时，对每种预定义的分辨率都进行一次前向传播，并累积损失进行反向传播。为了让单一模型适配多种分辨率，作者提出使用**分辨率感知的批归一化（Resolution-Aware Batch Normalization, RABN）**，即网络中的每个BN层都为每种输入分辨率保存一组独立的参数（均值、方差、缩放、偏移），而网络的其余权重在所有分辨率间共享。这引入了极小的额外内存开销，却显著提升了精度。
2.  **后训练分辨率合成**：
    - **仅限Pillar模型**：为了提供更细粒度的精度-延迟权衡，MURAL允许在训练后动态合成新的pillar尺寸。通过为每个BN层和每个通道拟合一个二次回归模型，根据已训练的BN参数值来预测新分辨率下的BN参数。此方法仅对基于2D卷积的Pillar模型有效，不适用于基于3D稀疏卷积的Voxel模型。
3.  **动态分辨率调度器**：
    - **核心逻辑**：调度器采用贪心策略，从最高分辨率（最小pillar）开始，依次预测其执行时间，选择第一个能满足截止时间约束的分辨率。
    - **精确时间预测**：将模型总延迟分解为四个部分：特征编码器（PFE）、稀疏CNN（SC）、密集CNN（DC）和后处理（PP）。
        - **DC和PP**：执行时间稳定，使用离线测得的**99百分位数**作为预测值。
        - **PFE**：与输入点云中的点数强相关，通过为每种分辨率拟合一个二次回归模型进行预测。
        - **SC（关键挑战）**：执行时间高度可变，取决于输入pillar的数目和空间分布。MURAL通过使用**轻量级最大池化操作**来模拟每个稀疏卷积层的输出pillar数量，从而准确预测SC的执行时间。对于Voxel模型，由于3D最大池化开销过大，则采用基于历史数据的**查表法**进行预测。

#### 算法流程（文字说明）
1.  **初始化**：系统接收一个LiDAR点云和当前截止时间 `d`。
2.  **调度**：调度器按分辨率从高到低（即pillar尺寸从小到大）遍历所有可用的分辨率。
3.  **预测**：对于每个候选分辨率 `p_i`，利用上述分解模型预测其总执行时间 `t_i`。
4.  **选择**：返回第一个满足 `t_i <= d` 的分辨率 `p_i`。如果所有分辨率都无法满足截止时间，则选择最粗糙的分辨率（执行最快）。

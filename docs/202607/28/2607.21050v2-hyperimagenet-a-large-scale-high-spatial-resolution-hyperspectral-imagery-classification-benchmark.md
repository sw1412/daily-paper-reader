## 摘要
我们提出了HyperImageNet，一个用于细粒度高光谱土地覆盖理解的大规模基准。该数据集包含26,084张机载高光谱影像块，具有224个光谱波段和138个细粒度土地覆盖类别。与现有数据集不同，HyperImageNet提供原始影像、像素级语义标签和对象级实例掩码，支持语义分割和实例分割。此外，我们建立了一个具有严格空间分离的开放环境基准，以评估代表性方法和HyperFree基础模型。实验结果证明了HyperImageNet在细粒度高光谱理解和开放环境遥感研究中的有效性。

## Abstract
We present HyperImageNet, a large-scale benchmark for fine-grained hyperspectral land-cover understanding. The dataset contains 26,084 airborne hyperspectral image patches with 224 spectral bands and 138 fine-grained land-cover categories. Unlike existing datasets, HyperImageNet provides raw imagery, pixel-level semantic labels, and object-level instance masks, supporting both semantic and instance segmentation. Furthermore, we establish an open-environment benchmark with strict spatial separation to evaluate representative methods and the HyperFree foundation model. Experimental results demonstrate the effectiveness of HyperImageNet for fine-grained hyperspectral understanding and open-environment remote sensing research.

## 1. 核心问题与整体含义（研究动机和背景）

- **高光谱遥感影像（HSI）的潜力与瓶颈**：HSI凭借连续细粒度的光谱特征，在精确土地覆盖分类、环境监测等领域具有显著优势，但高质量高光谱数据集极其稀缺，主要受限于采集成本高、空间分辨率限制、依赖专家知识的标注过程繁琐。数据短缺成为阻碍深度学习模型（尤其是大型基础模型）发展的关键瓶颈。
- **现有数据集的两大局限**：
  - **尺度与分辨率失衡**：绝大多数数据集数据量极小（如表I所列，经典数据集常只有单场景或少数图像），难以支持跨场景泛化评估；而部分大规模或高空间分辨率数据集往往只涵盖可见光-近红外（VNIR）波段，缺乏短波红外（SWIR）连续光谱。
  - **分类标签粒度不足**：主流数据集类别数通常不超过20，主要针对宏观土地覆盖类型，未能充分利用高光谱影像在细粒度分类上的固有优势。
- **基础模型的语义感知鸿沟**：新近提出的HyperFree框架虽在零样本分割上表现优异，但输出通常是语义无关的几何掩码，缺乏显式语义标签，限制了在特定场景级任务中的深入应用。
- **本文目标**：构建大规模**H²（高空间、高光谱分辨率）基准数据集HyperImageNet**，提供像素级语义标签和对象级实例掩码，并建立严格空间分离的开放环境评估协议，以推动细粒度高光谱理解和开放环境遥感研究。

## 2. 方法论：核心思想、关键技术细节

### 2.1 数据集构建

- **数据来源**：全部来自机载AVIRIS平台（AVIRIS-Classic和AVIRIS-NG传感器），原生提供224个连续光谱波段（380–2510 nm），空间分辨率0.5–5米。
- **预处理**：对AVIRIS-NG的425个波段通过中心波长匹配提取224个与AVIRIS-Classic高度对应的波段，实现跨传感器光谱对齐，形成统一特征空间。
- **标注策略**：
  - **多源标签融合**：根据不同年份采用差异化策略：
    - HyperSeg-A子集（2009–2022年）以USDA年度CDL栅格产品为基础；
    - HyperSeg-B子集（2023年）额外引入Overture Maps全像素采样点数据，实现语义互补。
  - **类别体系**：建立严格分层分类法，包含11个宏观大类（如农田、不透水面、森林、灌木、草地、湿地、水体、裸地、雪等），细分为138个子类别，涵盖80多种特定作物、不同物候特征的树木组分、精确建筑材料（如太阳能板、金属屋顶）、人工设施（如人工草皮）、水体性质区分（淡水/盐水）等。
  - **核心原则**：“细粒度优先”，即使某些类别有效像素极低也保留为独立类，以支撑长尾分布和稀有地物识别。
  - **空间对齐与人工校准**：通过经纬度网格匹配，将Overture Maps的JSON采样点映射到对应栅格像素；最终经仔细人工审查，建立与高光谱感知机制高度一致的138个细粒度子类别标签。
- **对象级掩码生成**：
  - 采用**HyperFree框架**，基于SAM的可提示分割架构，针对AVIRIS影像的复杂空间-光谱特性系统调优核心超参数（预测IoU阈值、稳定性分数阈值、特定波段特征输入范围）。
  - 后处理：形态学开运算分离粘连的小面积掩码，结合连通分量面积阈值进行过滤清洗，最终生成COCO格式高质量实例掩码，消除噪声同时保持精确几何边界。
- **最终数据集规模**：总计26,084张影像块（HyperSeg-A 22,699张，HyperSeg-B 3,385张），224个光谱波段，空间分辨率0.5–5米，138个细粒度类别，提供“原始影像（TIF）–像素级语义标签（TIF）–对象级实例掩码（COCO JSON）”三位一体数据结构。

### 2.2 开放环境评估协议

- 从全数据集中精选**562张高复杂度H²影像块**作为基准子集。
- 类别系统：31个已知类 + 1个“未知”类（第32类），未知类在训练阶段完全不可见，隐含21个具体未见子类别（如特定水稻类型）。
- 数据划分：按约7:3比例严格空间物理隔离拆分为训练集（383张）和测试集（179张），训练集和测试集在地理空间上完全独立，消除数据泄漏，考验模型真实泛化能力。

## 3. 实验设计：数据集/场景、基准、对比方法

### 3.1 封闭集二值分割基准

- **任务**：对31个已知类逐一进行One-vs-Rest二值分割，评估模型对单一土地覆盖的特征提取极限。
- **对比方法**（6种）：

  - UNet（Ronneberger等）

### 3.2 开放环境语义分割基准

- **任务**：32类联合分类（包含未知类），测试模型在开放环境中的识别能力。

## 6. 主要结论与发现

- HyperImageNet成功构建了大规模H²高光谱数据集（26,084张、224波段、138细粒度类别、三重标注），弥补了现有数据集在尺度、分辨率和粒度上的不足。

## 摘要
高光谱基础模型从大规模无标签数据中学习可迁移的光谱-空间表示。它们为在有限标签样本下适应下游高光谱图像（HSI）分类任务提供了一种有效范式。然而，不同传感器的光谱波段配置差异很大，这使得直接模型迁移困难。现有的适应策略通常对原始光谱进行压缩、选择或重塑，以匹配模型特定的输入要求。这些操作可能会丢弃有用的光谱信息并削弱局部光谱连续性。为解决这一问题，我们提出了MBTI，一种用于高光谱图像分类的多分支高效微调框架。MBTI在保留全波段光谱信息的同时，将高光谱基础模型适应到下游分类任务。首先，我们引入了一种保持光谱连续性的多分支预处理策略。原始HSI被划分为多个连续的光谱子集，并在剩余波段无法形成完整分支时使用波段重用机制。这避免了无效填充和不必要的光谱损失。其次，每个分支中插入独立的低秩适应（LoRA）模块。它们使得不同光谱区间能够学习任务特定的判别特征，同时保持大部分预训练参数冻结。最后，一个多分支通道注意力融合模块自适应地重新校准并整合来自所有光谱分支的特征。在三个公开高光谱数据集上的实验表明，与代表性分类方法相比，MBTI取得了具有竞争力且优越的性能。在最终秩为8的配置下，仅有约2.33%–2.36%的参数是可训练的。代码将在https://github.com/Azhenmiddleblock/MBTI/tree/main上提供。

## Abstract
Hyperspectral foundation models learn transferable spectral-spatial representations from large-scale unlabeled data. They provide an effective paradigm for adapting to downstream hyperspectral image (HSI) classification tasks with limited labeled samples. However, spectral band configurations vary substantially across sensors, which makes direct model transfer difficult. Existing adaptation strategies often compress, select, or reshape the original spectra to match model-specific input requirements. These operations may discard useful spectral information and weaken local spectral continuity. To address this problem, we propose MBTI, a Multi-Branch efficient fine-tuning framework for Hyperspectral Image classification. MBTI adapts hyperspectral foundation models to downstream classification tasks while preserving full-band spectral information. First, we introduce a spectral-continuity-preserving multi-branch preprocessing strategy. The original HSI is divided into multiple continuous spectral subsets, and a band reuse mechanism is used when the remaining bands cannot form a complete branch. This avoids invalid padding and unnecessary spectral loss. Second, independent Low-Rank Adaptation (LoRA) modules are inserted into each branch. They enable different spectral intervals to learn task-specific discriminative features while keeping most pre-trained parameters frozen. Finally, a multi-branch channel attention fusion module adaptively recalibrates and integrates features from all spectral branches. Experiments on three public hyperspectral datasets show that MBTI achieves competitive and superior performance compared with representative classification methods. Under the final rank-8 configuration, only about 2.33\%--2.36\% of the parameters are trainable. The code will be available at https://github.com/Azhenmiddleblock/MBTI/tree/main.

## 1. 核心问题与整体含义（研究动机和背景）

高光谱图像（HSI）具有丰富的空间结构和连续光谱响应，在精细地物分类中具有独特优势。近年来的高光谱基础模型（如 HyperSIGMA）通过大规模无标签预训练学习可迁移的光谱-空间表示，为少量标注样本下的分类任务提供了有效范式。然而，不同传感器获取的 HSI 在波段数量、波长覆盖范围、光谱间隔上差异显著，使得直接迁移预训练模型变得困难。现有适应策略往往通过压缩、选择、插值或重采样将原始光谱强制对齐到模型固定输入维度，这些操作**会丢弃有用光谱信息或破坏局部光谱连续性**，这对于依赖细微光谱差异的分类任务尤为不利。

**MBTI 的核心动机**：设计一个能够在保留全波段光谱信息和局部连续性的前提下，高效地将高光谱基础模型适应到不同传感器数据分类任务的框架。

## 2. 论文提出的方法论

### 核心思想
- **多分支结构**：将全波段 HSI 沿光谱维度划分为多个连续子集，每个子集输入一个独立的、基于相同预训练骨干的分支。
- **光谱连续性保持预处理**：当剩余波段不足以组成完整分支时，通过“重用上一分支末尾的连续波段”来补全，避免零填充或丢弃。
- **参数高效微调（PEFT）**：冻结所有分支的预训练骨干参数，在每个分支的 Transformer 层（Query、Key、Value、Output、FFN 线性层）插入独立的低秩适应（LoRA）模块（A、B 矩阵），仅训练少量参数。
- **多分支通道注意力融合**：将各分支投影后的特征沿通道维度拼接，通过轻量瓶颈网络（全连接 + ReLU + Sigmoid）学习通道重标定权重，自适应强调信息丰富的分支-通道响应，抑制冗余。

### 关键技术细节
- **分支划分**：设原始波段数为 \(B\)，每分支所需波段数为 \(M\)，分支数 \(N = \lceil B/M \rceil\)。前 \(N-1\) 分支取连续 \(M\) 波段；最后一分支若不足 \(M\) 波段，则从上一分支末尾借用 \(D = M - R\) 个连续波段（\(R\) 为剩余波段数），与剩余部分拼接构成完整输入。
- **LoRA 适配**：对于冻结的权重矩阵 \(W_0\)，可训练更新 \(\Delta W_i = \frac{\alpha}{r} B_i A_i\)（\(r\) 为秩，\(\alpha\) 为缩放因子）。前向变为 \(h = (W_0 + \Delta W_i)U_i\)。
- **多分支通道注意融合**：各分支输出经投影得到 \(Z_i \in \mathbb{R}^{L \times C}\)，拼接得 \(Z \in \mathbb{R}^{L \times NC}\)。沿 token 维度全局平均池化得通道描述子 \(s \in \mathbb{R}^{NC}\)，通过两全连接层（降维 \(\rho\) 再升维）加 Sigmoid 得到重标定权重 \(g\)，对 \(Z\) 逐通道相乘。最后经过 MLP 和线性分类器输出 logits。

### 算法流程（文字说明）
1. 对输入 HSI，根据预设 \(M\) 和 \(B\) 划分 \(N\) 个连续光谱子集，最后一分支采用波段重用策略。
2. 每个子集输入对应分支的 HyperSIGMA 编码器（冻结），编码器中每个目标线性层加入分支专属的 LoRA 低秩矩阵（可训练）。
3. 各分支输出经投影层得到紧凑特征 \(Z_i\)，通道拼接后通过多分支通道注意力模块计算重标定权重，加权融合。
4. 融合特征经 MLP 过渡头和线性分类器得到类别 logits，与真实标签计算交叉熵损失，仅优化 LoRA 矩阵、投影层、融合模块和分类器参数。

## 7. 优点

1. **针对光谱异构性的创新预处理**：通过连续子集划分+波段重用策略，**原生保留全波段光谱信息和局部连续性**，避免了刚性插值或压缩造成的信息损失。
2. **参数高效的适应方式**：采用分支级 LoRA，在冻结大骨干的同时为不同光谱区间学习个性化偏置，且仅极少量参数可训练，缓解小样本过拟合问题。
3. **自适应融合机制**：多分支通道注意模块综合考虑分支间重要性和通道间关联，增强判别性谱响应，抑制冗余。

## 摘要
噪声和损坏的点会显著降低点云识别性能，尤其是在具有挑战性的损坏条件下。特别是，对三维预训练模型进行全微调可能会放大异常值的影响并覆盖预训练期间学到的鲁棒性先验，而简单的参数高效自适应仍然对损坏的令牌敏感。为解决此问题，我们提出PSFT，一种点选择微调框架，在保持参数高效的同时提高鲁棒性。PSFT首先从池化前的特征中估计逐点影响力，并自适应地保留影响力最小的点以抑制异常值。基于选定的子集，提示生成分支预测逐层提示令牌，并将其注入冻结的主干网络，以实现轻量级下游自适应。为进一步减轻选择后的残余噪声，我们附加一个轻量级特征过滤器，使用瓶颈MLP变换和贝塔门控残差混合，在预测前细化补丁令牌表示。大量实验表明，PSFT在所有测试的三维预训练主干网络上一致地降低了ModelNet-C和ModelNet40-C上的损坏错误，同时在评估的微调策略中，使用ULIP-2和Uni3D-B获得了最强的ScanObjectNN-C结果。我们的实现可在https://github.com/CVChMA/PSFT/tree/master找到。

## Abstract
Noisy and corrupted points can substantially degrade point cloud recognition performance, especially under challenging corruption settings. In particular, full fine-tuning of 3D pre-trained models may amplify the influence of outliers and overwrite robustness priors learned during pre-training, while naive parameter-efficient adaptation remains sensitive to corrupted tokens. To address this issue, we propose PSFT, a point-selection fine-tuning framework that improves robustness while remaining parameter-efficient. PSFT first estimates point-wise influence from pre-pooling features and adaptively retains minimally influential points to suppress outliers. Based on the selected subset, a prompt generation branch predicts layer-wise prompt tokens and injects them into a frozen backbone for lightweight downstream adaptation. To further mitigate residual noise after selection, we append a lightweight feature filter with bottleneck MLP transformation and Beta-gated residual blending to refine patch-token representations before prediction. Extensive experiments show that PSFT consistently reduces corruption error on ModelNet-C and ModelNet40-C across all tested 3D pre-trained backbones, while achieving the strongest ScanObjectNN-C results with ULIP-2 and Uni3D-B among the evaluated tuning strategies. Our implementation can be found at https://github.com/CVChMA/PSFT/tree/master.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **点选择模块**：剔除高影响力（即可能是离群点）的点，只保留影响力最小的点作为后续处理的输入子集。
- **提示生成模块**：基于选定子集，通过EdgeConv生成逐层提示令牌（Prompt Tokens），注入冻结主干网络进行轻量适配。
- **特征过滤模块**：对编码器输出的令牌特征进行瓶颈MLP变换，并通过Beta门控残差混合（Stochastic Residual Blending）平衡去噪与信息保留。

### 关键技术细节
1. **点选择（Point Selection Module）**
   - 使用池化前特征图 `Xf ∈ R^(N×κ)`，定义每个点j的贡献得分：
     ```
     IF(j) = Σ_{k=1}^κ I( j = argmax_n Xf(n,k) )
     ```
   - 将得分归一化为概率分布p，计算熵H(p)并归一化Hn(p) ∈ [0,1]。
   - 自适应确定保留点数 S = clip(round((1-Hn(p))·N), 1, N)。
   - 按IF升序保留前S个最小影响力的点（低影响力点更可能是干净点）。

2. **提示生成（Prompt Generation Module）**
   - 使用EdgeConv网络从选定点中提取几何特征，预测每层Transformer的提示令牌Pi。
   - 冻结主干网络参数，仅训练提示生成分支。
   - 第i层输入序列：[Tcls, Pi, Ti]，其中Tcls为分类令牌，Ti为补丁令牌。

3. **特征过滤（Feature Filter Module, FFM）**
   - 为每个补丁令牌应用瓶颈MLP：`xf = DropOut(GELU(xo·Wdown))·Wup`，其中 `Wdown∈R^(d×d')`, `Wup∈R^(d'×d)`，瓶颈维度d' < d。
   - 残差混合：`xfinal = (1-α)·xf + α·xo`，其中 α ~ Beta(λ, λ) 在训练时随机采样（每样本共享一个α），测试时固定α≈0.5。
   - Beta分布提供有界插值与隐式正则化，λ较小时训练混合多样性更高。

## 6. 论文的主要结论与发现

1. **PSFT一致提升鲁棒性**：
   - 在ModelNet-C上，所有4种主干网络的mCE均降低（如ULIP-2从0.863降至0.530）。
   - 在ModelNet40-C上，PSFT显著降低mER（如ULIP-2从24.1%降至14.9%）。
   - 在ScanObjectNN-C上，对强主干（ULIP-2、Uni3D-B）最优（mCE 0.685、0.702），但对弱主干（Point-BERT、Point-MAE）反而略差（mCE升高）。
2. **参数效率**：PSFT仅需2.4M可训练参数（全微调22.1M），参数减少89.1%，但鲁棒性显著优于全微调。
3. **各模块贡献**：点选择是最关键的组件（单独使用mCE从0.863降至0.656），特征过滤进一步降低至0.558，三者结合达0.530。
4. **随机残差混合最优配置**：训练时α~Beta(0.5,0.5)，测试时α=0.5获得最佳鲁棒性。
5. **数据增强兼容性**：PSFT+WOLFMix在合成基准上进一步提升，但在ScanObjectNN-C上表现不稳定（受真实扫描噪声影响）。
6. **冻结主干的重要性**：与全微调相比，冻结主干可保留预训练鲁棒先验；提示生成从干净子集出发，避免噪声传播。

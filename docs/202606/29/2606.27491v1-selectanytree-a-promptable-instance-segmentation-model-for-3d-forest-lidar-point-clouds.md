## 摘要
随着森林监测向可扩展、精细化、三维测量方向发展，森林LiDAR点云的自动化实例分割变得越来越重要。然而，树实例标签的稀缺制约了进展：单公顷森林可能包含数百万个点和数百个重叠、复杂的树冠，从原始数据手动标注既费时又易出错。标注通常从自动预分割结果中修正得到，但由于缺乏交互式或AI辅助的细化，成本仍然高昂。受基础分割模型的可提示范式启发，我们提出SelectAnyTree，一种可提示的实例分割模型，通过少量点击即可描绘3D森林点云中的任意单棵树。它引入了两个关键组件：点击到查询的提示编码器和冠层高度模型（CHM）引导的初始提示。前者将每次点击转换为一个内容查询，编码其3D位置和正/负极性以及局部池化骨干特征。后者在无需任何用户输入的情况下，提供树冠顶部作为几何和生态学引导的初始提示。然后，通过状态空间查询解码器将生成的提示查询解码为一个树木掩码，以线性时间复杂度高效捕获大规模森林场景中的长程上下文。我们在七个不同森林区域和一个独立的留存测试数据集上评估了SelectAnyTree的交互式和实例级性能，展示了超越训练域的强泛化能力。它通过一次点击即可分割目标树，交并比（IoU）达到78.2，比最强的可提示基线高出24.8个百分点，并且以最少的点击次数达到每个准确率目标，同时参数数量和推理时间远少于之前的可提示模型。源代码可在https://github.com/thanhhff/SelectAnyTree获取。

## Abstract
Automated instance segmentation of forest LiDAR point clouds is increasingly critical as forest monitoring moves toward scalable, detailed, 3D measurement. Yet, progress is constrained by label scarcity for tree instances; a single hectare can hold millions of points and hundreds of overlapping, complex crowns, making manual annotation from scratch with raw data laborious and error-prone. Annotations are often corrected from automatic pre-segmentations, but remain costly as these provide no interactive or AI-assisted refinement. Inspired by the promptable paradigm of foundation segmentation models, we propose SelectAnyTree, a promptable instance segmentation model that delineates any individual tree in a 3D forest point cloud from a few clicks. It introduces two key components: Click-to-query prompt encoder and Canopy Height Model (CHM)-guided first prompt. The former turns each click into a single content query, encoding its 3D position and positive/negative polarity together with a pooled local backbone feature. The latter provides treetops as a geometry- and ecologically guided first prompt without any user input. The resulting prompt query is then decoded into one tree mask by a state-space query decoder to efficiently capture long-range context in large-scale forest scenes with linear-time complexity. We evaluate SelectAnyTree in interactive and instance-level settings across seven diverse forest regions and an independent held-out test dataset, demonstrating strong generalization beyond the training domains. It segments a target tree to 78.2 Intersection over Union (IoU) from a single click, 24.8 points above the strongest promptable baseline, and reaches every accuracy target with the fewest clicks, while using far fewer parameters and less inference time than prior promptable models. The source code is available at https://github.com/thanhhff/SelectAnyTree.

## 1. 核心问题与整体含义（研究动机和背景）

论文解决的是**3D森林LiDAR点云中单个树木实例分割的标签稀缺问题**。森林监测需要从点云数据中自动划分每棵树，但手动标注成本极高（单公顷数百万点、数百个重叠树冠）。现有方法多为全自动一次处理所有树木，缺乏用户交互能力，无法选择特定树或修正错误。受2D SAM模型“可提示分割”范式启发，作者提出SelectAnyTree，允许用户通过少量点击选择并分割任意单棵树，同时利用森林特有的几何结构（如冠层高度模型CHM）提供免费引导。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
将“可提示分割”扩展到3D森林点云：输入一个森林场景和一组点击（正/负），输出单个目标树的二进制掩码。场景特征一次性编码并缓存，多次点击共享特征，实现高效交互。

### 关键技术细节
- **3D场景编码器**：将点云体素化为0.2m分辨率，使用稀疏Mamba编码器生成体素特征，并记录点-体素映射。附设辅助分支用于树/非树分类和判别嵌入。
- **提示编码器（Click-to-query）**：将点击集转换为一个内容查询q。包含三部分：
  - **几何锚点**：在正点击周围水平半径rp=1.5m的圆柱内池化骨干特征，捕获局部冠层上下文。
  - **位置与标签编码**：点击坐标经随机傅里叶位置编码，极性（正/负）经学习嵌入，相加后通过MLP得到每个点击的token。
  - **有符号聚合**：正负点击token通过有符号平均聚合（正值拉近、负值推远），再与几何锚点残差相加得到最终查询q。
- **CHM引导的首次提示**：自动从冠层高度模型检测树冠顶部和内部点作为两个正点击，无需用户输入，提供几何和生态学先验。
- **状态空间查询解码器**：使用局部聚合+状态空间模型（Mamba）迭代细化查询，输出体素掩码logits和物体性分数，具有线性时间复杂度。
- **交互式回滚（Interactive Rollout）**：训练和评估共用同一模拟流程，首轮使用CHM+内部点，后续根据预测错误区域（假阴性/假阳性）自动添加修正点击，直到达到迭代次数T=5。

### 训练目标
联合优化：掩码损失（BCE+Dice，λdice=2.0）+ 辅助树/非树交叉熵 + 判别嵌入损失（拉近同树、推开异树）。权重均为1.0。

## 6. 主要结论与发现

- **交互式性能领先**：单次用户点击获得78.2 IoU，比最强可提示基线（Point-SAM 53.4）高出24.8个百分点；达到每个IoU目标所需点击次数最少（NoC@0.7=2.8，@0.8=3.7，@0.9=5.4）。
- **高效性**：参数仅19.4M（最小），5次点击推理549ms，GPU内存1.9GB，均优于基线（例如Point-SAM参数311M，时间8587ms，内存22.4GB）。
- **强泛化能力**：在未见过的LAUTx数据集上依然保持最低NoC和最高单点击IoU（77.0）。
- **CHM提示的有效性与局限性**：CHM提示在内分布上有帮助，但在跨数据集上无CHM变体反而更好，说明CHM先验需适应目标森林类型。
- **零点击性能**：在零点击设置下，SelectAnyTree F1=41.7，高于所有可提示基线（Point-SAM 35.9），但低于全自动方法（ForestMamba 83.4），符合预期——可提示模型优势在于交互而非全自动。

## 7. 优点

- **创新性**：首次将“SAM式”可提示分割引入3D森林LiDAR，设计了专门针对森林结构的提示编码和CHM引导。
- **简洁高效**：整个场景只编码一次，多次提示共享特征；解码器使用线性复杂度Mamba，参数量小，推理快。
- **训练-评估一致性**：共享相同的交互式回滚协议，避免优化与评测错配。
- **充分消融与公平性测试**：不仅消融CHM，还专门给基线提供免费CHM以证明设计不可替代。
- **开源**：提供源代码，可复现。

## 8. 不足与局限

- **CHM依赖**：CHM提示依赖于可靠的树体素预测，在多层密集冠层中可能退化；且固定的异速生长参数（α=0.25, β=0.5）可能不适用于所有森林类型，在跨数据集上无CHM变体反而更好。
- **实验覆盖有限**：仅两个数据集（一个内分布、一个跨域），未在更多不同传感器、不同气候区（如热带雨林深层结构）验证；未评估真实人类交互效果（模拟点击可能无法完全代表真实用户行为）。
- **偏差风险**：模拟点击策略（总是修正最大错误区域）可能导致模型过度适应这种特定修正模式，真实用户可能以不同顺序点击。
- **应用限制**：目前仅支持点击提示，不支持框、涂鸦等其他提示类型；不支持多掩码假设（如SAM对模糊点击输出多个候选）。
- **公平性细节**：基线微调时使用各自原生点击模拟协议，与SelectAnyTree的协议不完全相同，可能引入偏差。但作者已在附录中通过提供免费CHM进行公平性测试试图缓解。

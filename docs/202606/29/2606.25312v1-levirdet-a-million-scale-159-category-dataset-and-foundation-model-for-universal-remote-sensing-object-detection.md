## 摘要
遥感目标检测随着大规模基准数据集和现代检测架构的发展而快速进步。然而，现有数据集和检测器仍较为零散。大多数基准数据集关注有限类别、固定空间分辨率或单一传感器，而检测器仍然难以跨不同传感器和类别系统工作。本文介绍了LEVIRDet-159，这是迄今为止最大最全面的遥感目标检测数据集，包含159个类别、256万个边界框以及70万细粒度标注，采用多级分类体系。在每个关键尺度维度上，LEVIRDet-159都超过了现有最大的遥感目标检测数据集，图像数量约为（7倍）更多、目标实例约为（6倍）更多、类别数约为（4倍）更多。基于该数据集，我们设计了LEVIRDetNet，一种尺度层次感知的检测基础模型，用于通用遥感目标检测。LEVIRDetNet结合了在线视觉地面采样距离（GSD）预测、GSD条件查询调制与分配，以及用于混合粒度遥感监督的层次感知检测头部。在严格的评估设置下，LEVIRDetNet展现出强大的跨域泛化能力。即使没有目标域训练或微调，它在9个外部基准数据集上实现了最先进的检测性能，在各自基准的主要指标上平均比最强全监督竞争方法高出5.02 mAP。我们希望本研究能促进跨不同类别系统、空间分辨率和传感器平台的强泛化遥感目标检测的发展。数据集和训练模型将在最终论文附带的https://qinzheyang.github.io/LEVIRDet/上发布。

## Abstract
Remote sensing object detection has advanced rapidly with the development of large-scale benchmarks and modern detection architectures. However, existing datasets and detectors remain fragmented. Most benchmarks focus on limited categories, fixed spatial resolutions, or a single sensor, while detectors still struggle to work across different sensors and categorical systems. In this paper, we introduce LEVIRDet-159, the largest and most comprehensive remote sensing object detection dataset to date, with 159 categories, 2.56 million bounding boxes, and 700k fine-grained annotations under a multi-level taxonomy. In each key scale dimension, LEVIRDet-159 exceeds the corresponding largest existing remote sensing object detection dataset, containing approximately (7x) more images, (6x) more object instances, and (4x) more categories. Based on this dataset, we design LEVIRDetNet, a scale-hierarchy-aware detection foundation model for universal remote sensing object detection. LEVIRDetNet couples online visual Ground Sampling Distance (GSD) prediction, GSD-conditioned query modulation and allocation, and a hierarchy-aware detection head for mixed-granularity remote sensing supervision. Under stringent evaluation settings, LEVIRDetNet demonstrates strong cross-domain generalization. Even without target-domain training or fine-tuning, it achieves state-of-the-art detection performance on 9 external benchmarks, improving the strongest fully supervised competing methods by 5.02 mAP on average under each benchmark's primary metric. We hope this study will facilitate the development of strongly generalizable remote sensing object detection across diverse category systems, spatial resolutions, and sensor platforms. The dataset and trained models will be released at https://qinzheyang.github.io/LEVIRDet/, accompanying the final paper.

## 1. 核心问题与整体含义（研究动机和背景）

遥感目标检测在遥感图像分析中至关重要，但现有研究和系统面临两大核心瓶颈：**数据碎片化**与**模型泛化不足**。具体来说：
- **数据层面**：现有遥感检测基准数据集类别有限（多聚焦于小范围常见类别、单一家族如飞机/舰船/车辆）、分辨率固定、来源单一（卫星或航空单传感器），导致训练的模型难以适应真实世界中多样化的传感器、分辨率和地理场景。且不同数据集的边界框标注协议、类别定义不一致，直接合并会引起冲突。
- **模型层面**：现有检测器大多继承自然图像设计，缺少对**地面采样距离 (GSD)**、**场景密度**和**类别层级关系**这些遥感特殊因素的显式建模，因而难以在跨传感器、分辨率和类别系统的场景下有效泛化。

本文目标：构建一个**通用遥感目标检测框架**，通过大规模统一数据集和专为遥感设计的网络结构，实现无需目标域训练或微调即可在新场景下获得优异性能，推动遥感检测从“特定任务”走向“通用基础模型”。

## 2. 方法论

### 核心思想
提出包含两部分的工作：（1）**LEVIRDet-159数据集**——最大最全的百万级遥感检测基准，含159类、256万个边界框、70万细粒度标注，采用统一紧水平框（tight-HBB）协议和多级分类层次；（2）**LEVIRDetNet**——尺度层次感知的检测基础模型，通过在线视觉GSD预测、GSD条件查询调制、动态查询分配、层次感知分类头，实现对场景尺度、密度和语义粒度的联合建模。

### 关键技术细节

#### 2.1 数据引擎
分三阶段：
1. **Stage I - 几何优先父类标注**：统一为紧水平框，引入分割辅助检查框的紧密度，产生直接继承/修正/新增的父类框。
2. **Stage II - 源不可知细粒度重新标注**：裁切父类框后，隐藏来源信息由标注员进行细粒度分类（飞机、车辆、舰船子类），模糊实例保留父类标签，实现混合粒度标注。
3. **Stage III - 投影回看与全局校准**：将细粒度标签投影回原图，检查重复/遗漏/上下文不一致，多轮校准确保统一标注质量。

#### 2.2 LEVIRDetNet模型
建立在DEIM风格端到端检测器上（DINOv3 ViT骨干），新增三个耦合模块：

**（a）在线GSD预测器**  
- 从图像采样5个224×224块，提取三种互补特征：CNN特征、FFT频率特征、Sobel+Laplacian边缘特征。  
- 通过学习门控融合和注意力聚合得到图像级表示，回归预测GSD（对数压缩），生成GSD嵌入`z_g`。  
- `z_g`通过FILM调制作用于初始查询编码：`q̃_i = q_i ⊙ (1+λγ_g) + λβ_g`。

**（b）GSD引导的查询嵌入与动态分配**  
- 输入：全局编码器记忆`M̄`、GSD嵌入`z_g`、密度先验（编码器通道方差）、尺度先验（粗/细层级能量对比）。  
- 预测离散查询预算集合B={300,600,800}上的logits `π`，选择最大激活预算作为激活查询数，其余屏蔽。  
- 目标预算由真实目标数、小目标比例、归一化密度和尺度奖励共同计算；损失为交叉熵。

**（c）层次感知检测头**  
- 分类头输出所有层次节点的sigmoid分数，目标`t_c(y) = IoU(r)`对祖先路径有效，否则为0。  
- 引入类对权重矩阵`W`：祖先路径权重1，后代0，同位体`λ_sib`，同家族`λ_fam`，其他1。  
- 损失：加权的Varifocal损失`L_hcls = Σ_c W_{y,c} L_vfl(p_c, t_c(y))`。  
- 多级匹配：早期使用层次兼容的匈牙利匹配，后期切换到质量感知代价`C_switch = -ŷ·IoU^α`。  
- 推理时**树折叠预测**：用路径最小分数`s_path_c = min_{a∈A(c)} p_a`，再以深度微调选出最终类别`ĉ = argmax s_path_c · (1+ρ(depth-1))`。

### 关键创新点
- 数据统一与模型设计耦合：统一协议、混合粒度标注、类别层次。
- 显式建模遥感特异性因素（GSD、密度、层级关系），而非仅依赖数据规模。

## 6. 主要结论

1. **LEVIRDet-159**是目前最大、最全面的遥感检测数据集，统一标注协议、混合粒度层次结构，为通用模型提供坚实数据基础。
2. **LEVIRDetNet**在设计上对GSD、场景密度、语义层次显式建模，在9个外部基准上**无需目标域训练或微调**，平均mAP达80.56，比最强全监督对比方法的平均提升5.02 mAP，甚至超过各自目标域训练的SOTA。

4. 消融实验验证了每个模块（GSD条件、动态查询、层次头）对最终性能均有贡献，且GSD预测融合CNN/FFT/边缘特征最优，层次头优于扁平头处理混合粒度标签。

## 7. 优点

- **数据工程严谨**：3阶段数据引擎，不是简单合并，而是通过几何修正、细粒度重标注、全局校准产出一致、高密度、语义可靠的标注，超过90%的框是新建或修正的。
- **模型设计契合遥感特性**：在线GSD预测、动态查询分配、层次分类头三个模块分别解决尺度模糊、场景密度变化和混合粒度标签，克服了以往分离处理的不足。

## 8. 不足与局限

- **缺少明确训练算力报告**：未提及训练总GPU·小时数、使用的GPU数量、训练具体耗时，不利于资源评估和复现。

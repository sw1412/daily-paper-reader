## 摘要
高光谱目标跟踪利用丰富的光谱信息，在复杂场景中为目标判别提供独特优势。然而，现有方法通常将高光谱图像视为RGB图像的多通道扩展，以固定的波段顺序进行特征融合。这种方式导致模型依赖于特定传感器配置，同时忽略了波段间的流形关系，使得泛化到异构传感器变得困难。此外，波段的判别性贡献会随着目标属性和场景变化而动态改变，进一步限制了静态融合策略的表征能力。为解决这一问题，我们提出了流形引导光谱提示网络（MSP-Net）。该网络首先通过图驱动的流形路由重建波段关系并形成自适应光谱分组，然后将分组后的光谱统计信息与模板外观联合整合，构建与目标相关的动态条件提示，增强目标特征同时抑制背景干扰。此外，随着跟踪的进行，光谱条件基于中间目标表示不断演化，使目标提示能够实时适应外观和场景变化。同时，利用可靠的历史状态约束目标定位和尺度波动，显著提高跨传感器跟踪的时间稳定性。在HOT2020和HOT2023上的实验表明，MSP-Net的AUC和精确度分别超过0.80和0.96，在异构传感器、目标变形和复杂背景条件下展现出卓越的鲁棒性。代码将在https://github.com/GGML668897/MSP-Net发布。

## Abstract
Hyperspectral object tracking leverages abundant spectral information to provide unique advantages for target discrimination in complex scenes. However, existing methods typically treat hyperspectral images as multi-channel extensions of RGB images, performing feature fusion in fixed band order. This approach leads to models dependent on specific sensor configurations while neglecting manifold relationships between bands, making generalization to heterogeneous sensors difficult. Moreover, the discriminative contribution of bands dynamically changes with target attributes and scene variations, further limiting the representational capacity of static fusion strategies. To address this, we propose the Manifold-Guided Spectral Prompt Network (MSP-Net). This network first reconstructs band relationships and forms adaptive spectral grouping through graph-driven manifold routing, then jointly integrates grouped spectral statistics with template appearance to construct target-related dynamic conditional prompts, enhancing target features while suppressing background interference. Furthermore, as tracking progresses, spectral conditions continuously evolve based on intermediate target representations, enabling target prompts to adapt in real-time to appearance and scene changes. Meanwhile, reliable historical states are used to constrain target localization and scale fluctuations, significantly improving temporal stability in cross-sensor tracking. Experiments on HOT2020 and HOT2023 demonstrate that MSP-Net achieves AUC and Precision exceeding 0.80 and 0.96, respectively, exhibiting exceptional robustness under heterogeneous sensors, target deformation, and complex background conditions. The code will be released at https://github.com/GGML668897/MSP-Net.

## 1. 核心问题与整体含义

**研究动机**：高光谱目标跟踪利用丰富的光谱信息来实现复杂场景下的目标判别，理论上优于仅依赖 RGB 信息的传统跟踪方法。然而，现有方法存在三大核心问题：

- **忽略波段间流形关系**：现有方法普遍将高光谱图像视为 RGB 图像的多通道扩展，以固定波段顺序进行特征融合，破坏了波段之间内在的非线性拓扑结构（即光谱流形），导致模型依赖特定传感器配置，跨传感器泛化困难。
- **静态融合策略表达能力有限**：波段的判别性贡献会随目标属性（材质、形状）和场景条件（光照、遮挡）动态变化，固定波段分组（如图1所示的固定分组、顺序分组、权重分组）无法适应这种动态变化。
- **长时序跟踪中的特征滞后**：照明变化、遮挡和目标形变会使基于首帧的光谱先验逐渐失效，静态提示和固定尺度惩罚难以在变形适应与漂移抑制之间取得平衡。

**核心含义**：论文提出一种统一框架 MSP-Net，将流形感知的光谱建模、目标条件化的动态提示生成和时间状态记忆三者联合建模，旨在同时解决光谱信息丢失、特征滞后和跟踪漂移问题，实现跨传感器、长时序、复杂场景下的鲁棒高光谱目标跟踪。

## 2. 方法论

MSP-Net 由四个核心模块组成，形成"流形感知分组 → 动态提示调制 → 条件在线演化 → 时序稳定后处理"的完整流水线：

### 2.1 Graph-Driven Manifold Spectral Routing（GMSR）—— 图驱动流形光谱路由

- **核心思想**：将光谱分组问题形式化为可学习的路由问题。将每个光谱波段视为图节点，根据特征相似度动态构建边，使信息能够在语义相关的波段间传播和聚合，实现超越固定波长约束的场景自适应分组。
- **关键步骤**：
  1. 对输入高光谱张量 X∈R^{B×C×H×W} 进行自适应平均池化，得到光谱节点表示 V = AdaptiveAvgPool2d(X)。
  2. 计算节点间成对平方欧氏距离，通过动态高斯核构造特征邻接矩阵 A（含可学习带宽参数 σ 和防除零常数 ε）。
  3. 对邻接矩阵进行对称归一化（度矩阵 D 的 −1/2 次幂）以稳定梯度传播。
  4. 使用图卷积权重矩阵 W_gcn 在流形上进行信息传播和聚合，H_new = GELU(Ã·V·W_gcn)，权重通过反向传播更新。
  5. **状态感知动态路由**：训练阶段使用 Gumbel-Softmax 硬分配产生离散 one-hot 路由决策；推理阶段切换到 softmax 软分配以平滑边界。
  6. 通过路由矩阵对更新后的节点特征进行加权聚合生成 F_group，再投影生成专家混合权重 W_moe = Softmax(F_group W_proj)，同时用于后续加权融合和提示调制。

### 2.2 Dual-Stream Spectral-Conditioned Prompt Modulation（DSCPM）—— 双流光谱条件提示调制

- **核心思想**：动态生成场景自适应提示，联合利用光谱流形上下文和目标任务外观线索，区分空间结构相似但光谱特征不同的目标。
- **关键细节**：
  1. 对每个分组特征 F_group 提取多维统计（空间/通道均值表征全局低频上下文，标准差捕获高频光谱波动），构成分组波段条件向量 C_group。
  2. 提取模板特征的均值与最大响应生成模板条件向量 C_template，编码目标几何与纹理特征。
  3. 将 C_group、C_template 与 MoE 权重 W_moe 拼接，得到解耦的光谱-目标双流条件向量 C_cond = Concat(C_group, C_template, W_moe)。
  4. **条件提示生成器**将 C_cond 端到端映射为动态提示向量 P。
  5. **跨注意力注入**：以输入图像 tokens X_in 为 Query、动态提示 P 为 Key/Value 进行跨注意力调制（含 √d_h 缩放因子防止梯度饱和）。
  6. **余弦相似度门控**：计算 X_in 与提示中心的余弦相似度并经 Sigmoid 生成空间掩码 M = σ(γ·CosSim(X_in, P_center) + β)，防止提示信息干扰背景区域。
  7. 最终调制输出 X_out = X_in + α(M ⊙ X_attn)，带残差连接。

### 2.3 Decoupled Spectral-Condition Evolution（DSCE）—— 解耦光谱条件演化

- **核心思想**：目标外观和光照在长序列中持续变化，首帧光谱先验会逐渐失效。DSCE 在不引入额外参数、不做在线微调的前提下，利用中间层模板特征周期性地在线更新光谱条件。
- **关键细节**：
  1. 在视觉 Transformer 的选定层（Ω = {3, 6, 9}）中，从拼接后的模板-搜索 token 序列中切分出深层模板表示 Z^(l)。
  2. 通过条件演化规则更新 C_cond：当 l ∈ Ω 时用 F_group、W_moe 和 Z^(l) 重新提取条件；否则保持之前条件。
  3. 提示生成器基于最新条件生成对应层的动态视觉提示 P^(l) = G_prompt(C_cond^(l))。
  4. **训练阶段**条件演化机制不激活，C_cond = C_cond^(0)，保证骨干网络稳定收敛；**推理阶段**动态激活，随网络深度渐进校准提示。

### 2.4 Temporal Morphology Memory-Adaptive Post-processing（TMMA）—— 时间形态记忆自适应后处理

- **核心思想**：通过空间跳跃锁定和形态波动感知，区分真实的非刚体变形与干扰物引起的偏移，自适应稳定边界框。
- **关键细节**：
  1. 计算当前中心与上一帧中心的欧氏距离 Δd 与当前目标对角线长度 D_t 的比值，定义空间跳跃指示函数 I_jump（λ=0.5）。
  2. 当置信度超过阈值 τ_s 且无空间跳变时，将宽高比 r_t 和面积 a_t 存入长度 K=8 的滑动窗口记忆库。
  3. 从记忆库计算宽高比方差 V_r 和面积最大-最小波动率 F_a。
  4. 离散门控调制尺度惩罚因子 η_size：当 V_r > μ_r 或 F_a > μ_a 时判定为变形，η_size=1.00（不惩罚）；否则 η_size=η_base=0.99。
  5. 实验设定阈值 μ_r=0.04、μ_a=0.20。

   - GMSR 贡献最大（+7.35% AUC），验证了流形感知光谱分组的重要性；
   - DSCPM 的余弦门控对抑制背景干扰至关重要（移除后 AUC 下降 2.52%）；
   - DSCE 虽单独不评估，但消除 GMSR 和 DSCPM 之间的失配（+1.17%），说明条件在线演化对模块协调不可或缺；
   - TMMA 在高质量预测基础上可进一步稳定跟踪（−0.70% AUC 当移除时）。
4. **效率优势**：MSP-Net 以 34.71 FPS 达到最高推理速度，在精度-效率之间取得良好平衡。
5. **局限性发现**：在 HOT2024 的 VIS 和 RedNIR 模态下表现不如 SOTA，归因于训练域与测试域之间的分布偏移以及光谱维度过低时高维特征挖掘优势受限。

## 7. 优点

### 方法设计方面

1. **流形建模创新性强**：将高光谱波段间关系显式建模为图结构，突破了固定波段顺序的束缚，自适应地将非相邻但语义相关的波段聚合到同一特征组，物理可解释性强。
2. **动态提示设计完备**：DSCPM 联合光谱统计、模板外观和 MoE 权重三重信息构建条件，配合余弦门控精确控制提示注入的位置和强度，实现了"有条件的增强、有选择性的调制"。
3. **参数高效的在线适应**：DSCE 通过"训练时静态、推理时动态"的解耦策略，在不引入任何额外参数的前提下实现条件在线演化，兼顾了训练稳定性和推理自适应能力，工程实用性突出。
4. **后处理模块轻量有效**：TMMA 通过简单的历史形态统计（宽高比方差、面积波动率）区分真实变形与干扰漂移，以离散门控方式调节尺度惩罚，设计简洁而有效。
5. **Gumbel-Softmax 到 Softmax 的训练-推理切换**设计合理，兼顾了训练时明确的分组边界与推理时的稳定性。

### 实验验证方面

6. **多数据集多模态验证**：覆盖 HOT2020/2023/2024 和 IMEC25 四个基准、三种光谱模态，共 8 项属性分析，跨域泛化验证扎实。
7. **消融实验设计规范**：逐模块引入、单独模块移除、结构变体对比、节点粒度分析多层次展开，因果归因清晰。
8. **可视化分析丰富**：提供了流形分组效果、特征调制差异图、跟踪轨迹对比和失败案例，兼具层次性和诊断价值。

## 8. 不足与局限

### 实验覆盖方面

1. **HOT2024 VIS 和 RedNIR 模态表现不佳**：AUC 仅 0.4819 和 0.5044，明显落后于 UBSTrack（0.5474）和 HOT-MoE（0.5434）等方法。作者将此归因于分布偏移和光谱维度不足，但这也暴露出方法在域偏移和低光谱信息条件下的脆弱性。
2. **IMEC25 上 AUC 未达最优**：AUC 0.7381 低于 ProFit 的 0.7540，说明跨域迁移能力并不全面。
3. **消融实验范围偏窄**：所有消融仅在 HOT2020 单数据集上完成，未在更大规模或跨模态数据集上验证组件通用性。

### 方法局限性

4. **训练-推理行为不一致风险**：Gumbel-Softmax 硬路由与 softmax 软路由之间的差异虽然缓解了推理不稳定，但模型的训练分布与推理分布之间存在系统性偏差，可能影响最优性能。
5. **图表标注存在乱码**：图3和图4中疑似存在OCR提取错误的符号（如"Xn″、"CosSim"等），影响可读性准确性。
6. **TMMA 参数为手工

6. **TMMA 参数为手工设定且缺乏自适应能力**：TMMA 中的多个关键参数（跳跃阈值 λ=0.5、置信度阈值 τ_s、记忆库长度 K=8、宽高比方差阈值 μ_r=0.04、面积波动率阈值 μ_a=0.20）均依赖人工经验设定，在不同数据集或复杂场景下未必最优。同时，该模块仅利用宽高比和面积的历史统计，未整合置信度变化趋势或运动轨迹等更丰富的时间信息，对于快慢形变混合、长期遮挡后恢复正常尺寸等复杂情况，其判别能力仍显不足。

## 9. 总体评价与总结

MSP-Net 针对高光谱目标跟踪中光谱流形信息利用不足、静态特征融合和长时序漂移三大痛点，提出了一个由 GMSR、DSCPM、DSCE、TMMA 构成的完整解决方案。该方法在多个基准上取得了领先精度，同时保持了约 35 FPS 的实时推理速度，展示了良好的精度-效率平衡。其核心创新——将光谱波段关系建模为可学习的图结构、利用联合条件动态生成提示、以及通过解耦演化机制实现参数高效的在线适应——为高光谱视觉任务提供了新的思路。

然而，该方法在跨域场景（如 HOT2024 VIS/RedNIR）上性能退化明显，消融实验仅在单一数据集上进行，手工参数较多，且训练-推理行为存在固有偏差，其鲁棒性和通用性仍有提升空间。未来工作可考虑引入域自适应机制、自动搜索最优超参数、以及更丰富的时间-光谱联合建模。

总体而言，MSP-Net 是一项设计精巧、实验扎实、具有明确应用价值的研究工作，在高光谱目标跟踪方向上达到了当前最优水平，其局限也指明了后续改进方向。

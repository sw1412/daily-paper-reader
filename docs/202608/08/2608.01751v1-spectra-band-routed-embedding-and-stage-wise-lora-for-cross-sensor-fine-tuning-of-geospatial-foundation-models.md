## 摘要
地理空间基础模型（GeoFMs）在大规模地理空间数据（如地球观测（EO）、气候和天气数据）上预训练，在微调到多种下游任务时展现出了良好的性能。然而，将EO预训练的GeoFMs适配到实际下游数据集存在两个挑战：第一个挑战是如何处理光谱不匹配，即预训练的块嵌入期望固定的输入波段集合，而下游传感器可能提供不同的通道；第二个挑战是如何降低微调成本并使其高效。虽然现有工作已分别针对这些挑战做出了努力，但在光谱不匹配条件下联合提升微调性能同时降低适配成本的问题仍未得到充分探索。为此，我们提出了SPECTRA，一个参数高效的微调框架，同时解决光谱不匹配和适配成本问题。为了处理光谱不匹配，SPECTRA引入了波段路由嵌入（BRE），它将所有可用的下游波段映射到预训练GeoFM所期望的波段空间。通过使用BRE，下游数据集中的所有可用波段都被利用来改进所选波段的输入，而无需改变预训练的块嵌入接口。为了降低适配成本，SPECTRA进一步引入了阶段式可迁移性感知LoRA（ST-LoRA）微调。ST-LoRA在微调前估计各阶段的可迁移性，并为各阶段分配特定的LoRA秩，将可训练参数集中在目标任务具有高可迁移性的阶段。在三个EO预训练GeoFMs和四个下游分割数据集上的实验表明，BRE通过利用所有光谱波段提升了性能，而ST-LoRA相比全量微调和标准LoRA减少了可训练参数。代码可在 https://github.com/big-data-lab-umbc/SPECTRA 获取。

## Abstract
Geospatial foundation models (GeoFMs), pretrained on large-scale geospatial data such as Earth observation (EO), climate, and weather data, have shown promising performance when fine-tuned on diverse downstream tasks. However, there are two challenges of adapting EO-pretrained GeoFMs to practical downstream datasets. The first challenge is how to handle spectral mismatch: pretrained patch embeddings expect a fixed set of input bands, whereas downstream sensors may provide different channels. The second challenge is how to reduce fine-tuning cost and make it efficient. While existing work has made efforts on these challenges individually, jointly improving fine-tuning performance under spectral mismatch while reducing adaptation cost remains underexplored. We propose SPECTRA, a parameter-efficient fine-tuning framework that addresses both spectral mismatch and adaptation cost. To handle spectral mismatch, SPECTRA introduces Band-Routed Embedding (BRE), which maps all available downstream bands into the band space expected by the pretrained GeoFM. By using BRE, all available bands in the downstream dataset are utilized to improve the selected-band input without changing the pretrained patch embedding interface. To reduce adaptation cost, SPECTRA further introduces a Stage-wise Transferability-aware LoRA (ST-LoRA) fine-tuning. ST-LoRA estimates stage-wise transferability before fine-tuning and assigns stage-specific LoRA ranks, concentrating trainable parameters on the stages with high transferability for the target task. Across three EO-pretrained GeoFMs and four downstream segmentation datasets, experiments show that BRE improves performance by utilizing all spectral bands, while ST-LoRA reduces trainable parameters compared with full fine-tuning and standard LoRA. Code is available at https://github.com/big-data-lab-umbc/SPECTRA.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：地理空间基础模型（GeoFMs）在遥感等大规模地球观测数据上预训练后，可通过微调适配多种下游任务（如洪水分割、火烧迹地检测、滑坡识别、作物分类）。典型的预训练流程采用掩码自编码器（MAE）风格，输入图像被切分为 patches，经 patch embedding 投影为 token，再送入 ViT 编码器。
- **核心问题一：光谱不匹配（Spectral Mismatch）**  
  预训练模型中的 patch embedding 层在预训练时固定了输入波段的数量、顺序和光谱含义（例如 Prithvi-EO-2.0 期望 6 个 HLS 光学波段，ScaleMAE 仅接受 RGB 三波段，SatMAE 接受 10 个 Sentinel-2 波段）。然而，下游数据集常来自不同传感器，可能包含更多或不同的多光谱波段。常用的兼容策略是“波段选择”（band-selection），即从下游波段中挑选与预训练波段物理波长最匹配的子集，而丢弃其余波段。这种策略虽然保持预训练接口稳定，但丢弃的波段可能含有对下游任务有用的信息。
- **核心问题二：微调成本高**  
  全量微调会更新预训练编码器的全部参数，GPU 内存、优化时间和存储开销都很大。参数高效微调（PEFT）方法（如 LoRA）虽能降低成本，但标准 LoRA 通常对所有层或阶段使用相同的秩，未考虑不同编码器阶段对目标任务的可迁移性差异。
- **整体含义**：现有工作分别处理光谱适配或参数高效微调，但尚未联合解决“在光谱不匹配条件下提升微调性能同时降低适配成本”的问题。SPECTRA 旨在填补这一空白，为跨传感器 GeoFM 微调提供既充分利用光谱信息又控制可训练参数预算的框架。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

SPECTRA 包含两个核心组件：**波段路由嵌入（Band-Routed Embedding, BRE）** 和**阶段式可迁移性感知 LoRA（Stage-wise Transferability-aware LoRA, ST-LoRA）**。整体流程为：BRE 将全波段图像转换为与预训练模型兼容的“虚拟图像” → 预训练 patch embedding 对其分块 → 预训练 ViT 编码器（各阶段被 ST-LoRA 以不同秩适配）提取特征 → UPerNet 解码器输出分割结果。

### 2.1 Band-Routed Embedding (BRE)

- **目标**：学习映射 $A_\theta: \mathbb{R}^{C \times H \times W} \to \mathbb{R}^{K \times H \times W}$，其中 $C$ 为下游可用波段数，$K$ 为预训练模型期望的波段数，要求所有 $C$ 个波段均参与贡献，无硬丢弃。
- **两条路径**：
  1. **Selected-band anchor（上路径）**：保留原有的波段选择结果 $X_{\text{sel}} = P_{\text{sel}}(X)$，作为物理上有依据的锚点，使初始输入接近预训练分布。
  2. **All-band residual path（下路径）**：对所有 $C$ 个输入波段应用学习到的门控，再经一个共享的轻量残差适配器（1×1 卷积网络）生成残差 $\Delta_\theta(X)$。
- **输出公式**：$X_{\text{BRE}} = X_{\text{sel}} + \Delta_\theta(X)$。
- **门控设计**：可学习门控表 $G \in \mathbb{R}^{K \times C}$，其中 $G_{j,i} = 2\,\text{sigmoid}(L_{j,i})$，初始化为 $L=0$，故所有门初始值为 1，保留所有源波段信号。每个虚拟波段 $j$ 对应一个由所有 $C$ 个门控通道拼接而成的张量 $U_j$，最后将所有 $K$ 个虚拟波段的门控张量拼接成 $U \in \mathbb{R}^{KC \times H \times W}$，送入共享残差适配器。
- **零初始化**：残差路径的最后一层零初始化，因此初始化时 $X_{\text{BRE}} = X_{\text{sel}}$，即从稳定的波段选择基线开始微调，避免直接学习随机投影破坏预训练接口。
- **作用**：所有下游波段均可影响任意虚拟预训练波段，从而“充分使用所有波段”，但同时保持预训练 patch embedding 接口不变。

### 2.2 Stage-wise Transferability-aware LoRA (ST-LoRA)

- **目标**：在微调前估计预训练编码器各阶段的可迁移性，并据此分配各阶段的 LoRA 秩，使可训练参数集中在高可迁移性阶段，降低总参数预算。
- **Transferability 评估**：使用冻结特征的 LogME 指标。将选中的波段输入预训练 patch embedding，逐层提取各阶段特征 $\Phi_s$，对 patch token 与分割标签进行匹配（仅保留主类别纯度超过阈值的 patch），计算每个阶段的 LogME 分数 $q_s = \text{LogME}(\Phi_s(X_{\text{sel}}), Y)$。
- **两种规划模式**：
  - **Transfer 模式**：$a_s = q_s$，高可迁移性阶段分配更多秩。
  - **Repair 模式**：$a_s = \max_s q_s - q_s$，低可迁移性阶段分配更多秩（用于修复）。
- **预算控制**：以标准均匀 LoRA-${r_{\text{ref}}}$ 为参照，定义总秩预算 $T_{\text{rank}}(r_{\text{ref}}) = S \cdot r_{\text{ref}}$（$S$ 为阶段数）。允许阶段秩从离散集合 $\mathcal{R}(r_{\text{ref}}) = \{0, 4, 8, \dots, r_{\text{ref}}/2, r_{\text{ref}}, 2r_{\text{ref}}\}$ 中取值，总秩不超过预算。
- **分配算法**：利用温度 $\tau$ 将信号 $a_s$ 归一化为权重 $w_s$，计算连续秩 $\tilde{r}_s = T_{\text{rank}} w_s$，量化为不超过该值的最大离散值，再用贪心算法将剩余预算分配给量化误差最大的阶段，直至满足约束。
- **Nested LoRA**：每个阶段的线性层使用“嵌套 LoRA”，即先构建最大秩 $r_{\max}=2r_{\text{ref}}$ 的 LoRA 矩阵，实际使用时截取前 $r_s$ 行/列。若 $r_s=0$，该阶段不注入 LoRA，完全冻结。
- **最终训练目标**：最小化分割损失（交叉熵 + Dice 损失，由 DWA 动态加权），训练参数包括 BRE 模块参数 $\theta$、LoRA 参数 $\phi$ 和解码器参数 $\eta$；预训练编码器权重 $\omega$ 保持冻结。

## 6. 论文的主要结论与发现

1. **BRE 能有效利用所有光谱波段并带来一致的性能提升**：
   - 在 60 个匹配单元中，BRE 相比波段选择基线平均提升 macro mIoU +2.88 点；而直接 MLP 投影平均下降 −2.28 点。
   - BRE 在前景 F1 上提升 56/60 个单元，平均 +3.08 F1；FG IoU 平均 +4.15。
   - 增益最大的场景是 ScaleMAE（RGB 接口 vs 多光谱下游），如 Sen1Floods11 上从 LoRA-64 的 77.17 提升到 85.45 macro mIoU。
   - 当预训练与下游波段天然匹配时（如 Prithvi–FireScars），BRE 无显著增益，说明其收益是条件性的。

2. **ST-LoRA 能在降低参数预算的同时保持或提升精度**：
   - SPECTRA 的总可训练参数仅为全量微调的 3.29%–7.73%，在多数设置下优于或接近均匀 LoRA-32/64，甚至在多个数据集上超过 Full-FT。
   - 例如 Prithvi–Sen1Floods11 上，SPECTRA 以 4.06% 参数达到 86.39 macro mIoU，高于 LoRA-32 的 85.10 和 Full-FT 的 86.24。
   - ST-LoRA 自动分配的秩（如 [8,16,16,8] 或 [16,32,16,16]）与手工最优调度相当，但无需穷举搜索。

3. **MLP 直接投影失败的原因**：直接混合所有波段会改变预训练 patch embedding 的输入分布，破坏预训练 tokenizer，而 BRE 通过零初始化残差保持初始分布，实现渐进式适配。

4. **整体结论**：SPECTRA 提供了一种高精度、低成本的跨传感器 GeoFM 微调方案，尤其适用于预训练与下游光谱差异大的场景。

## 7. 优点

- **问题导向明确**：同时解决光谱不匹配和参数效率两个实际痛点，具有现实部署价值。
- **方法设计巧妙**：
  - BRE 采用“锚点 + 零初始化残差”的保守策略，兼顾物理先验（保留波段选择）和灵活学习（利用全波段），避免直接投影带来的分布偏移。
  - 门控机制数学形式简洁（sigmoid 双倍缩放），保证了初始时所有波段贡献相同，无硬性丢弃。
  - ST-LoRA 将 LogME 可迁移性指标首次用于阶段级 LoRA 秩分配，在微调前即可完成规划，计算开销低。
  - 嵌套 LoRA 实现同一套矩阵可适应不同阶段秩，工程实现简洁。
- **实验系统性强**：覆盖 3 个骨干、4 个数据集、5 种基线策略、多种指标，且进行多达 60 组的配对比较；同时提供定性可视化（如图 3 显示 ScaleMAE 分割细节的显著改善），支撑结论的可信度。
- **注重公平性**：统一 decoder、固定随机种子、采用相同训练预算，并在相同参数预算下对比 LoRA 和 Full-FT，结论较为客观。
- **坦诚报告边界**：明确说明在天然匹配场景下 BRE 无增益，并区分 SPECTRA 作为“低成本的替代方案”而非“所有情况下的最优解”。

## 8. 不足与局限

- **ST-LoRA 验证范围不足**：秩规划实验仅在 Sen1Floods11 上完成，未在其他三个数据集上验证自动秩分配的泛化性。
- **数据集多样性有限**：所有数据集均为分割任务，未涉及检测、回归、变化检测等；下游数据以光学为主（虽含 DEM 辅助通道），未涵盖 SAR（除 Sen1Floods11 名称外实际使用 Sentinel-2 光学波段）、高光谱等其他模态。
- **超参数非最优**：统一使用 UPerNet 和固定学习率等设置，可能掩盖某些方法在特定数据集上的最佳表现，因此论文不主张达到每个数据集的 state-of-the-art。
- **潜在偏差风险**：SPECTRA 在多个情况下同时使用 BRE 和 ST-LoRA，尽管有消融实验，但两者的交互效应未完全解耦（例如表 4 中的 SPECTRA 同时包含两个组件；表 6 中的 ST-LoRA 是在 BRE 存在下的评估）。
- **可复现性细节不足**：论文未给出完整训练超参数（如具体学习率、batch size、patch 大小等），仅指向 GitHub，审稿时可能影响独立验证。
- **未提及计算成本细节**：缺少训练时间、内存占用等量化对比，只报告了参数数量比例，对“效率”的体现不完整。
- **手工调度仅作对照**：8 组手工秩分配并不覆盖所有可能，ST-LoRA 的优势主要是自动化和参数效率，而非绝对精度领先；个别情况下手工调度（如 M1）也能取得与 ST-LoRA 相当的精度。

**总体评价**：SPECTRA 是一篇方法新颖、实验较扎实的跨传感器 GeoFM 微调工作，尤其在光谱适配的“保守残差”思想上有所创新，但后续仍需在更多任务和数据集上验证 ST-LoRA 的普适性，并补充更完整的训练与资源报告。

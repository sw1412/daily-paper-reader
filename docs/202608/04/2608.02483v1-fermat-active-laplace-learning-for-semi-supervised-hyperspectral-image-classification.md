## 摘要
提出了两种用于高光谱图像(HSI)分类的主动学习算法，它们将密度感知的费马距离与泊松重加权调和标签传播相结合。我们的方法使用基于不确定性的采集函数主动查询点，扩展了泊松重加权拉普拉斯学习(PWLL)。我们的第一种算法，费马主动拉普拉斯学习(FALL)，使用所有数据点之间的费马距离构建亲和矩阵。然后，使用最小范数采集函数通过对角扰动运行PWLL。相比之下，近似FALL(A-FALL)计算每个数据点与通过最远点采样选定的地标像素之间的费马距离，并使用地标多维缩放构建亲和矩阵。经过多轮查询后，A-FALL使用留一交叉验证变体选择费马指数$p$。FALL和A-FALL利用费马距离和后续的调和标签传播来提供数据流形的密度感知估计，从而提高标注准确性。在Salinas A和Pavia上的实验显示了FALL的有效性以及A-FALL对大型HSI场景的可扩展性。

## Abstract
Two active learning algorithms for hyperspectral image (HSI) classification are proposed that combine density-aware Fermat distances with Poisson-reweighted harmonic label propagation. Our methods actively query points using an uncertainty-based acquisition function, extending Poisson ReWeighted Laplace Learning (PWLL). Our first algorithm, Fermat Active Laplace Learning (FALL), builds an affinity matrix using Fermat distances between all data points. Then, PWLL is run with a diagonal perturbation using the minimum-norm acquisition function. In contrast, Approximate FALL (A-FALL) computes Fermat distances between each data point and landmark pixels selected via farthest-point sampling and constructs the affinity matrix using landmark multidimensional scaling. After several query rounds, A-FALL selects the Fermat exponent $p$ using a leave-one-out cross-validation variant. FALL and A-FALL leverage Fermat distances and subsequent harmonic label propagation to provide a density-aware estimation of the data manifold, improving labeling accuracy. Experiments on Salinas A and Pavia show the effectiveness of FALL and the scalability of A-FALL to large HSI scenes.

## 1. 核心问题与整体含义

高光谱图像（HSI）分类在遥感领域具有重要应用，但监督学习方法通常依赖大量人工标注样本，成本高昂。为缓解标注稀缺问题，半监督学习和主动学习成为重要途径。现有图半监督方法（如拉普拉斯学习、泊松学习）虽在低标签率下取得较好效果，但其图亲和矩阵多基于欧氏距离或 RBF 核，缺乏对数据流形密度的感知，导致分类精度受限。

本文提出 **FALL（Fermat Active Laplace Learning）** 与 **A-FALL（Approximate FALL）** 两种主动学习算法，将 **Fermat 距离**（密度感知的加权最短路径距离）与 **Poisson Reweighted Laplace Learning（PWLL）** 相结合，利用不确定性采样主动查询最具信息量的像素。其核心动机是：Fermat 距离能够更好地反映数据流形的几何与密度结构，从而提升低标签率下的标签传播质量。

## 2. 方法论

### 2.1 Fermat 距离

给定数据点集 \(X=\{x_i\}_{i=1}^N \subset \mathbb{R}^D\)，离散 p 加权 Fermat 距离定义为：

\[
\ell_p(x_i, x_j) = \min_{\pi=\{x_k\}_{k=1}^T} \left( \sum_{k=1}^{T-1} \|x_k - x_{k+1}\|^p \right)^{1/p}
\]

其中路径 \(\pi\) 经过数据点，起点 \(x_1=x_i\)，终点 \(x_T=x_j\)。当 \(p\) 增大时，路径更偏好经过高密度区域，从而具有密度感知能力。为高效计算，可采用 kNN 图上的 Dijkstra 算法，复杂度约为 \(O(N^2 \log^2 N)\)。

### 2.2 PWLL-τ 与主动学习

PWLL-τ 通过最小化带重加权函数 \(\gamma\) 的 Dirichlet 能量进行标签传播：

\[
\min_u \sum_{x_i, x_j} \frac{1}{2} \gamma(x_i)\gamma(x_j) W_{ij} \|u(x_i)-u(x_j)\|^2 + \tau \sum_{x_i \in U} \|u(x_i)\|^2
\]

满足 \(u(x)=e_{y(x)}\) 对标记点 \(x\in L\)。\(\gamma\) 由图泊松方程求解，\(\tau\) 控制对角扰动。分类结果取 \(u(x)\) 的最大分量。

主动学习采用最小范数采集函数 \(A(x_i)=\|u(x_i)\|\)，每次查询未标记点中 \(A\) 最小的点，以实现探索与利用的平衡。

### 2.3 地标多维缩放（LMDS）

为降低 Fermat 距离计算成本，A-FALL 使用最远点采样（FPS）选择 \(m=300\) 个地标点，计算数据点到地标点的 Fermat 距离，再通过 LMDS 将数据嵌入 \(r=32\) 维空间中，近似原始 Fermat 几何。

### 2.4 学习 Fermat 指数 p

- **ELOO（精确留一交叉验证）**：对每个候选 p 和每个标记点 a，将 a 留出后重新求解 PWLL，计算预测误差，代价高昂（需 \(|P||L|\) 次求解）。
- **ALOO（近似留一交叉验证）**：利用 Kron reduction 得到的 Schur 补，一次性基于所有标记点求解，再通过线性近似计算留一预测：

\[
F_{p,a}^{(R_a)} = -\frac{S_{p,aR_a} Y_{R_a}}{S_{p,aa} + \tau}
\]

ALOO 大幅降低了计算开销，并引入置信边际项正则化评分。

### 2.5 算法流程

- **FALL**：计算所有点间 Fermat 距离，构建亲和矩阵，迭代执行：求解 PWLL → 选择最小范数点 → 查询标签 → 更新标记集；最终用全部标记点运行 PWLL 得到分类。
- **A-FALL**：先 FPS 选择地标，对每个候选 p 构建 LMDS 嵌入和自调谐高斯核权重；每 T 轮用 ALOO 选择最优 p；其余与 FALL 相同。

## 6. 主要结论与发现

- FALL 和 A-FALL 在低标签率下显著优于 PWLL-τ，说明 Fermat 距离提供的密度感知流形结构有助于提高标签传播精度。
- FALL 在 Salinas A 上达到最高 OA/AA（约 0.984），但全量 Fermat 距离计算开销较大。
- A-FALL 通过 LMDS 近似 Fermat 距离，在保持接近 FALL 精度的同时大幅降低运行时间（Pavia 子集上甚至超过 FALL），具备更好的可扩展性。
- ALOO 作为 ELOO 的近似，在几乎不损失精度的前提下，将 p 学习时间减少了约 60%，验证了 Kron reduction 加速策略的有效性。
- 密度感知的路径距离与主动学习结合是半监督 HSI 分类的一种有前景的方向。

## 7. 优点

- **方法新颖**：首次将 Fermat 距离引入主动学习框架下的 PWLL，提升了对数据流形密度的感知。
